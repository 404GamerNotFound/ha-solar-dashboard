# Code of Conduct

## Our Pledge

We want this project to be a friendly, respectful, and productive place for everyone who uses or contributes to HA Solar Dashboard Card.

Everyone participating in this project is expected to act with empathy, patience, and professionalism. This applies in issues, pull requests, discussions, reviews, and any other project space.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent when clarification is needed.
- Keep bug reports and reviews focused on reproducible facts and actionable feedback.
- Accept that maintainers may need to prioritize some work over other work.
- Respect different levels of Home Assistant, HACS, JavaScript, and frontend experience.

## Unacceptable Behavior

- Harassment, intimidation, or personal attacks.
- Insults, discriminatory language, or exclusionary behavior.
- Publishing private information without consent.
- Spam, repeated off-topic comments, or demands for immediate support.
- Any behavior that makes the project unsafe or unwelcoming for others.

## Enforcement

Maintainers may remove comments, close issues, block users, or take other appropriate action when this Code of Conduct is violated.

If you need to report a problem, open a private channel with the maintainer if one is available. If not, report the behavior through GitHub's reporting tools.

## Attribution

This Code of Conduct is inspired by the Contributor Covenant and adapted for this project.
