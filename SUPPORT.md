# Support

Use the following channels depending on what you need.

## Questions and Configuration Help

Open a GitHub discussion if discussions are enabled. If not, open an issue and choose the most relevant template.

Please include your card YAML, Home Assistant version, browser, and screenshots when layout or rendering is involved. Remove secrets, tokens, private URLs, and personal entity names if needed.

## Bug Reports

Use the bug report template and include a minimal configuration that reproduces the issue.

Good bug reports include:

- What you expected to happen
- What actually happened
- Browser console errors
- Relevant Home Assistant logs
- Screenshots for visual issues

## Feature Requests

Use the feature request template. Explain the practical Home Assistant or solar-dashboard use case, not just the UI control you want added.

## Security Issues

Do not open public issues for vulnerabilities. Follow `SECURITY.md`.

## Maintainer Availability

This is an open source project. Support is best-effort and response times may vary.
